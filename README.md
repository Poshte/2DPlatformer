# 2D Platformer Game

## Overview

This project is a work in progress developed in Unity, featuring a custom physics system designed to enhance gameplay mechanics. 

## Features

- **Custom Physics and collision System**: Designed to handle complex interactions such as moving platforms and how they behave when transferring a passenger, climbing and descending slopes and tight controls that give you the feeling of total agency when moving or jumping (or both!).

- **Dialogue System**: Interactive dialogue system that has been coded from scratch to enhance storytelling and player engagement.

- **Data Persistence and Diary** Developed a system that logs in-game events to present the data as a form of player's diary.
